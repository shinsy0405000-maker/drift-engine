# 5단계: 차량 물리 + 오픈월드

작성: 2026-10-28

## 결정 사항

- 물리 엔진: Jolt Physics (C++), Java 바인딩 jolt-jni 6.2.0 (MIT, Maven Central, 미리 빌드된 Windows 네이티브 포함)
  - 이 프로젝트에 C++ 코드가 늘지 않는다 → Java 비중 유지 (사용자 조건: Java 90% 이상이면 C++ 엔진 사용)
  - Jolt 담당: 강체 적분, 지형/물체 충돌, 광선 검사. Java 담당: 서스펜션, 타이어, 구동계, 드리프트 보조
  - 엔진의 다른 코드는 physics.PhysicsWorld 만 쓰고 Jolt 클래스를 직접 쓰지 않는다
- 주행감: 세미 시뮬 (실제 타이어 곡선 + 키보드용 보조, 보조 강도는 설정 파일)
- 입력: 키보드만 (조향·가속을 서서히 올려 아날로그처럼)

## 단계

- 5a: jolt-jni 로드, 높이맵 지형 충돌체, 상자 떨어뜨리기, 지형 그리기  (완료, PC 확인)
- 5b: 차체 강체 + 광선 서스펜션 4개 (차가 떨어져 바퀴로 서 있음)  (완료, PC 확인: 정지 높이 오차 0, 물리 0.73ms/틱)
- 2026-10-28 일정 변경: 시연 마감 때문에 남은 단계를 큰 덩어리로 묶음 (덩어리마다 PC 실행 확인 한 번)
  - 덩어리 A (5c + 5d): 타이어, 엔진·터보, 변속기, LSD, 핸드브레이크, 드리프트 보조, 차 파일 여러 대  (완료, PC 확인)
  - 덩어리 B: 그래픽
    - B-1: 차체 생성기 + 바디킷 + 바퀴, PBR 재질, 하늘·구름·해, 공기 원근감, 톤매핑, 차고 장면  ← 현재, PC 실행 확인 전
    - B-2: 그림자 맵, 블룸, 타이어 연기, 스키드 마크
  - 덩어리 C: 맵 (서킷 + 산길 + 도시, 구역별 불러오기)  (구현, PC 확인 전) — 지역마다 원점이 따로라 기준점 이동은 필요 없음
  - 덩어리 D: 게임 시스템 (돈, 클럽, 드리프트 점수, 레이스, 튜닝, 바디킷, 클래스 점수 1~CS+, 딜러쉽 4클래스까지)
  - 덩어리 E: 소리 (배기음 합성: 실린더 수·점화 간격·로터리·전기 모터, 터보·블로우오프)
  - 덩어리 F: 메뉴, 화면 UI
- 차와 소리는 모두 가상 (실제 차 디자인·이름·녹음 사용 안 함). 성능 숫자만 실제 차급 참고

## 5a 파일

- `physics/JoltNative.java`: joltjni.dll 을 jar 에서 natives/jolt/ 로 꺼내 로드, Jolt 전역 초기화 (jolt-jni 문서 순서)
- `physics/PhysicsWorld.java`: Jolt 물리 세계 감싸기. 충돌 층 2개(정적/움직임), 지형·상자 추가, step, 위치·회전·속력, 아래 방향 광선
- `world/Terrain.java`: 높이맵 지형 (생성, 높이 보간, 법선, 메시). 삼각형 대각선을 Jolt HeightFieldShape 와 같게
- `world/TerrainScene.java`: 지형 + 상자 장면. 시작 시 Jolt 광선 높이 vs Java 높이 비교, 5초 뒤 상자 정지 확인을 로그로
- `scene/Scene.java`: 장면 인터페이스 (DemoScene, TerrainScene 공통)
- `--scene=terrain|demo`: 기본 terrain. 물리 엔진 시작에 실패하면 demo 로 자동 대체

## 5b 파일

- `math/Quat.java`: 쿼터니언 (벡터 회전, 축-각, nlerp 보간)
- `vehicle/CarSpec.java`: 차 제원 (1300kg, 바퀴 위치, 서스펜션 길이·반지름). 스프링은 정지 눌림 10cm, 감쇠비 0.35 가 되게 계산
- `vehicle/Suspension.java`: 눌림·힘 계산 (순수 함수, 공중이면 0, 당기는 힘 없음)
- `vehicle/Car.java`: Jolt 차체 강체 하나 + 바퀴마다 아래로 광선 → 서스펜션 힘을 고정점에 가함. 물리 스텝마다 prePhysics() 먼저
- `scene/ChaseCamera.java`: 차 뒤 위쪽에서 부드럽게 따라가는 카메라. C 키로 자유 카메라와 전환
- `physics/PhysicsWorld.java`: 차량 층(2) 추가, 차체 추가(무게중심 낮춤, 잠들지 않음), 점에 힘 주기, 속도·각속도, 정적 물체만 맞는 광선
- `world/TerrainScene.java`: 차 생성(평지, 1m 위에서 떨어뜨림), 60Hz 틱 안에서 4번 나눠 계산(240Hz), 그리기 보간, 4초 뒤 "차 정지 확인" 로그
- `scene/Scene.java`: interpolate(alpha), followTarget() 추가
- 자체 테스트 `VehicleTests`: 서스펜션 힘, 제원 계산, 1/4 차량 모의(240Hz 로 떨어뜨려 계산한 눌림에 멈추는지), 쿼터니언, 추적 카메라

## 덩어리 A 파일

- `vehicle/Tire.java`, `TireSpec.java`: 결합 슬립 타이어 (슬립률·슬립각을 최고점으로 정규화해 합침, sin(C·atan(B·s)) 곡선, 하중 민감도)
- `vehicle/Engine.java`, `EngineSpec.java`: 토크 곡선(스톡 다이노 곡선 → 부스트 0 곡선으로 환산), 출발 클러치 미끄러짐, 레드존 연료 차단, 엔진 브레이크. 피스톤/로터리/전기
- `vehicle/Turbo.java`, `TurboSpec.java`: 부스트 = 회전수 구간 × 스로틀, 배기 흐름에 비례해 차오름(랙), 스로틀 떼면 0.12초로 빠짐, 블로우오프 횟수(소리 신호)
- `vehicle/Gearbox.java`, `GearboxSpec.java`: 자동/수동, 변속 중 동력 끊김, 올림은 바퀴·땅 회전수 중 낮은 값, 내림은 높은 값으로 판단(휠스핀·잠김에 속지 않음), 드리프트·핸드브레이크 중에는 내리지 않음
- `vehicle/Differential.java`: LSD (한도 = preload + lock × 축 토크, 한도 안이면 잠김). 한 스텝에 회전 차이를 뒤집지 않음
- `vehicle/Car.java`: 전체 조립. 바퀴 회전은 타이어 기울기를 관성에 더하는 암시적 적분(작은 바퀴 관성에서도 240Hz 안정). 저속 슬립 분모 2m/s 하한
  - 키보드 보조: 조향 최대각을 속도에 맞춰 줄임(L·μg/v² + 슬립각 1/4), 카운터 보조(0.25초 뒤 예상 β 쪽으로 앞바퀴), 각이 한계를 넘을 것 같으면 스로틀 줄임 + 회전 보조
  - 핸드브레이크 = 뒷바퀴 제동 + 클러치 끊음, ABS, 스태빌라이저, 공기저항, 다운포스
- `vehicle/CarSpec.java`, `CarSpecLoader.java`: 차 파일 읽기. 스프링·댐퍼는 정지 눌림·감쇠비로 계산(앞뒤 수평). 터보는 turbo.boost 가 있을 때만
- `vehicle/VehicleBody.java` + `physics/JoltVehicleBody.java`: 차 계산이 강체에 요구하는 것. 게임은 Jolt, 자체 테스트는 순수 Java 강체
- `cars/*.properties`: 가상 차 9대 (드리프트 6: RT-7 로터리 터보, SR-15 직4 터보, 86R 자연흡기, Coupe 3.8 V6, N-Volt 5/6 전기 사륜 / 서킷 3: GT-M V8 트윈터보, FC-74 수소 전기, Fujin-R 3로터 프로토)
- `world/TerrainScene.java`: 511m 지형(가운데 반지름 120m 평지), 차 바꾸기(N), 세우기(T), 창 제목에 속도·기어·RPM·부스트·드리프트 각, 0→100 시간·드리프트 로그
- Jolt 차체 몸체의 선 감쇠 0 (기본 0.05 는 시속 160km 에서 2800N 저항이라 끔)
- 자체 테스트 `DrivingTests` + `SimpleRigidBody` + `DriveSim`: 게임과 같은 Car 코드로 평지 운전 시험 (정지, 0→100, 최고 속도, 제동 거리, 조향 방향, 핸드브레이크 드리프트, 시속 150 슬라럼, 차 9대 전부)

## 렌더러 울트라 (GPU 여유 전제, 효과마다 끄는 옵션)

- `render/RenderSettings` 기본 = 울트라. 실행 옵션으로 끄거나 조절 (`.\gradlew run -Ddrift.ao=off` 처럼 Gradle 에 주면 게임으로 넘어감):
  `-Ddrift.shadows=off` `-Ddrift.shadowSize=2048` `-Ddrift.ao=off` `-Ddrift.flakes=off` `-Ddrift.glass=off`(유리 안 그림)
  `-Ddrift.fog=0`(높이 안개) `-Ddrift.mblur=0` `-Ddrift.flare=0` `-Ddrift.grain=0` `-Ddrift.ca=0`(색수차) `-Ddrift.bloom=0`
  `-Ddrift.tonemap=agx|aces` `-Ddrift.saturation=1.0`
- `render/CascadedShadows` 해 그림자 4단계 (끝 9 / 28 / 85 / 260m), 4096² 배열 한 장, 단계마다 감싸는 공 + 텍셀 스냅.
  지형도 그림자를 드리움 (언덕 그림자). 반투명 물체는 안 드리움
- `lighting.glsl` 16탭 포아송 PCF, 단계 사이 섞기, 접촉 그림자, 카본 무늬, 아스팔트 미세 법선, 도장 금속 입자 반짝임
- `render/SkyLut` + `sky_lut.frag` 대기 산란(레일리 + 미) 하늘 표 256×128. 하늘·반사·안개가 모두 이 표를 읽음
- `sky.frag` 구름 fbm 5단 + 해 쪽 은빛 테두리. `fx.frag`·불투명 안개도 하늘 표 색
- `render/AmbientOcclusion` + `ao.frag`·`ao_blur.frag` 깊이만 그리는 단계(prepass) 뒤 화면 공간 AO, 깊이 고려 흐림
- 유리: `glass.frag` 반투명(프레넬로 가장자리 반사↑), 먼 것부터 정렬해 효과 단계와 같이 그림
- `post.frag` 모션 블러(모션 벡터 12탭), 색수차, 렌즈 플레어(해가 화면 안 + 블룸 있을 때), AgX/ACES 톤매핑, 필름 그레인
- `shaders/frame.glsl` 공통 UBO 720 바이트 (`FrameUniforms` 와 같은 순서, 시험이 글자로 대조)
- 그리는 순서: 하늘 표 → 그림자 4단계 → (AO 켜면) 깊이 단계 + AO → 불투명 + 하늘 → 유리 + 연기·자국 → (DLSS) → 블룸 → 후처리
- 시험: `FxTests` (단계 그림자 행렬, uniform 배치, 셰이더 필드 순서·오프셋)

- 시험: `selftest/MemoryTests`

## 덩어리 C: 맵 (지역 4곳)

- 지역: 연습장(기존, 샵 2곳) · 용인 서킷 · 태백 고갯길 · 도시. 한 번에 한 지역만 불러온다 (`world/map/Zone`)
  - Tab → "지역 이동", 또는 클럽 이벤트를 고르면 그 지역으로. 샵으로 이동하면 연습장으로
  - 지역마다 원점이 가운데라 좌표가 800m 안 → 소수점 오차 문제 없음 (기준점 이동 안 함)
  - 지역을 바꾸면 물리 세계를 새로 만들고 차를 다시 세운다 (한 번 만든 지역은 기억해서 두 번째부터 빠름)
- 용인 서킷 (가상): 3.6km 시계 방향, 메인 스트레이트 700m, 헤어핀, S자, 고속 스위퍼, 높낮이 ±20m, 폭 13m
  - 굽은 곳 빨강·흰 연석, 출발선 + 출발 문(신호등), 관중석 4동, 피트 건물, 양쪽 콘크리트 벽(중심에서 19.5m), 나무
  - 자유 주행: 출발선을 지나면 랩 시간 (오른쪽 위, 최고 기록)
- 태백 고갯길 (가상): 3.2km 편도 다운힐, 정상 255m → 25m (경사 7.5%), 지그재그 4구간 + 헤어핀 3개(반지름 약 11m), 폭 8.4m
  - 노란 중앙 이중선, 양쪽 가드레일, 침엽수 숲, 정상 표지, 아래 휴게소
- 도시: 6×6 블록 (블록 72m, 도로 16m), 가운데 남북 대로 노란 중앙선, 횡단보도, 인도, 건물(층마다 창 띠), 가로등(인도 안쪽 끝), 드리프트 광장(블록 2×2 + 사이 도로 = 160m, 원 두 개), 공원
  - "도심 주차장" 이벤트는 광장에서 출발
- 차가 땅 아래로 빠지면 그 자리 위로 다시 올리고 로그에 "차가 땅 아래로 빠짐"(위치·속도·가까운 상자)을 남김. 차체 연속 충돌(LinearCast) 켬
- 멀어진 지형 조각의 자세한 메시는 GPU 에 남겨 둠 (다가가고 멀어질 때마다 다시 올리지 않게)
- 만드는 법 (`world/map`): 도로 중심선(캐트멀-롬, 1m 간격) → 지형 = 도로 높이 가중 평균 + 먼 곳 기본 지형 + 노이즈 → 도로 새기기(포장+갓길 평평, 22m(서킷)/14m(산) 동안 원래 지형으로)
  - 도로 면은 지형(= 물리) 높이 위 3cm 띠, 차선·연석은 정점 색 (셰이더 SURFACE_ROAD = 7). 도로 아래 지형 칸은 그리지 않음
  - 지형 조각 64칸: 220m 안은 자세히(1.5m), 밖은 듬성(6m, 도로 근처는 낮춤). 자세한 조각은 다가갈 때 프레임마다 3개씩 만들고 최근 140개만 둠
  - 지도 밖 3km 는 성긴 먼 땅 (그림자·물리 없음), 가장자리에 보이지 않는 벽
- 이벤트: 서킷 = 출발선부터 한 바퀴 랩타임 (체크포인트 순서대로, 목표 × 2 + 20초 넘으면 실패), 고갯길 = 결승선까지 드리프트 점수 (5분 제한), 연습장·도시 = 60초 드리프트 점수
  - 새 이벤트: 골목 드리프터즈 "도심 주차장" (도시)
- 랩 목표 시간: 컴퓨터 운전자(`selftest/LapBot`, 실제 차 물리, 평지)가 24대로 돈 시간으로 다시 정함 (클래스 1 약 125~132초, 4 약 106~112초, CS+ 84~98초)
  - 보스 목표 ≥ 그 클럽 클래스 이하 순정 차 가장 빠른 컴퓨터 랩 / 1.02 (시험으로 확인)
- T (차 세우기): 도로에서 벗어나 있으면 가장 가까운 도로 가운데로. 떨어지면 도로로
- 카메라 near/far: 0.1/1000 → 0.2/2600 (먼 산까지, 도로 면 3cm 띄움이 먼 곳에서 깜빡이지 않게)
- 클래스 정리: SX-14·CR-33·Cruiser JX → 클래스 2, JZ-80·R-3X → 클래스 4 (토크·그립 올림). 1/2/3/4 = 4/6/4/4대
- 시험: `selftest/MapTests` (도로 모양·높이·경사, 도로 면 높이, 벽 위치, 도시 도로 비움, 삼각형 예산, 코스 문·랩 기록, 컴퓨터 운전자 한 바퀴, 랩 목표, 클래스 분포)
- 미리보기: `selftest/MapShot` (GPU 없이 CPU 로 그린 배치 확인용 그림)

## 덩어리 C 확인할 것 (PC)

- Tab → 지역 이동 → 각 지역: 로그 "지역 → …(ms)", "지형 높이 비교 … 일치", "지형 조각 (…): 자세히 n / 256"
- 서킷: 출발선 지나 한 바퀴 → 화면 오른쪽 위 랩 시간, 로그 "연습 랩"
- 클럽 → 용인 서킷 클럽 → 첫 랩: 카운트다운 → 출발선 지나면 시간 시작 → 한 바퀴 → 결과
- 고갯길: 태백 다운힐 이벤트로 결승선까지, 가드레일에 부딪혀 보기
- 도시: 건물·가로등 충돌, 주차장 드리프트
- GPU 단계 시간 (특히 그림자) — 숲·건물이 그림자를 드리움. 느리면 알려 주기
- 먼 곳 지형·도로가 깜빡이거나 구멍이 보이는지
